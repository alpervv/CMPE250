# CMPE250
## Overview  
Magical Map is a project for **CmpE 250: Data Structures and Algorithms**  that challenges users to navigate an enchanted land using an **adaptive pathfinding algorithm**. The land, shattered and shuffled by Wizard Oz, requires visitors to explore efficiently, uncover hidden obstacles, and make strategic decisions to unlock paths.

## Input & Output  
- **Input:** Land structure, movement costs, and objectives (provided in structured text files).
- **Output:** Movement log, impassable path detections, and choices made when offered help.
  
## Run the Code  
To compile and run the program, follow these steps:  

1. **Compile the Java files:**  
   ```sh
   javac *.java
   ```
2. **Run the program with an input file:**
   ```sh
   java Main <land_file> <travel_time_file> <mission_file> <output_file> 
   ```
